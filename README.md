## 📌 Project Overview

**Namo Traders** is a Laravel-based web application designed for managing business and trading operations.  
The project is deployed on a Linux production server and uses Laravel Scheduler (Cron) for automated background tasks.

---

## 🧰 Tech Stack

- **Framework:** Laravel
- **Language:** PHP
- **Database:** MySQL
- **Server OS:** Linux (Ubuntu / CentOS)
- **Web Server:** Apache / Nginx
- **PHP Version:** 7.4+
- **Dependency Manager:** Composer
